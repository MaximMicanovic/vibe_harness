Write a Python CLI script in the current directory.

Requirements:
- Uses only the Python standard library.
- Takes command-line arguments with argparse (at least one required argument and one optional flag).
- Prints structured output and exits 0 on success, non-zero with a clear error message on failure.
- Includes a `--help` that is actually useful.
- Add a `test_*.py` using unittest that tests the core logic (import the script as a module; keep the logic in functions, not under `if __name__ == "__main__"`).
- Run the tests and make sure they pass.
