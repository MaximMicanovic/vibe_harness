Build a small single-page web app in the current directory.

Requirements:
- Framework of your choice (or none), but it must run by just opening the files or being served statically.
- A dark-mode toggle that persists its setting in localStorage.
- A list of at least three items fetched from a mock data source (an inline JS array is fine; do not call a real backend).
- Each item shows a title, a short description, and a colored status badge.
- A search input that filters the list as you type.
- A "Add item" form that appends a new item to the list.
- Write a small test (plain JS run with `node`, or a tiny HTML test page) that verifies the filter logic works.
